Duedle

導入方法

PCで使う方はこちら

iPhone・iPad（Safari）

  1. Duedleアプリをインストールする

    インストールはこちら

  2. Safariの機能拡張の設定を開く

    端末の「設定」アプリを開き、「アプリ」→「Safari」→「機能拡張」→「Duedle」と進みます。「アプリ」が見当たらない場合は、「設定」から直接「Safari」を開いてください。

  3. DuedleをONにする

    「機能拡張を許可」をONにします。

  4. Moodleでの利用を許可する

    Safariで名工大Moodleの入口ページを開きます。ログイン前に、画面下部または上部のメニューからDuedleを選び、「常に許可」→「このWebサイトで常に許可」と進みます。

  5. Duedleが表示されるか確認する

    左上に「Duedle: Extended」が表示されたら、「Moodleログイン」からログインします。

設定にDuedleが出てこない

Duedleアプリがインストールされているか確認してください。アプリを一度開いてから、設定アプリでSafariの「機能拡張」を開き直します。

Appleの案内：Safariの機能拡張を設定する

PCで使う

  • Chrome（Windows・Mac）
  • Safari（Mac）

PC（Chrome）

ChromeウェブストアからDuedleを追加します。WindowsでもMacでも、操作は同じです。

  1. ChromeでDuedleのページを開く

    PCのChromeで、DuedleのChromeウェブストアページを開きます。

  2. 「Chromeに追加」を押す

    確認画面が表示されたら、内容を確認して「拡張機能を追加」を押します。

  3. Moodleを開く

    名工大Moodleにログインして、再読み込みを行なってください。

  4. Duedleが表示されるか確認する

    左上に「Duedle: Extended」が表示されていれば、拡張機能が動いています。

「Chromeから削除」と表示されている

すでにインストールされています。そのままMoodleを開いてください。Duedleが表示されない場合は、Chrome右上のメニューから「拡張機能」→「拡張機能を管理」を開き、DuedleがONになっているか確認します。

「Chromeに追加」を押せない・追加できない

PCのChromeで開いているか確認してください。学校のPCでは、拡張機能の追加が制限されている場合があります。

Mac（Safari）

  1. Duedleアプリをインストールする

    インストールはこちら

  2. Safariの機能拡張の設定を開く

    Safariを開き、画面上部のメニューバーで「Safari」→「設定」→「機能拡張」と進みます。

  3. DuedleをONにする

    「Duedle」のチェックをONにします。

  4. Moodleでの利用を許可する

    Safariで名工大Moodleを開いてログインします。SafariのツールバーからDuedleを選び、「常に許可」をクリックしてください。

  5. Duedleが表示されるか確認する

    左上に「Duedle: Extended」が表示されていれば、拡張機能が動いています。

設定にDuedleが出てこない

Duedleアプリがインストールされているか確認してください。アプリを一度開いてから、Safariの「設定」→「機能拡張」を開き直します。
